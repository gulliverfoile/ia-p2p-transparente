NETWORK QUEST 1.0 - Protocol Simulation SuiteNetwork Quest es un entorno de simulación educativo que emula el comportamiento de las capas 3, 4 y 7 del modelo OSI. Permite experimentar con protocolos de transporte, redes de anonimato y sistemas descentralizados en una topología de red dinámica.🧪 Protocolos ImplementadosHTTP (Capa 7): Simulación de métodos GET/POST y códigos de estado.TCP (Capa 4): Implementación de Three-Way Handshake (SYN, SYN-ACK, ACK) y gestión de estados de conexión.Onion Routing (Privacidad): Cifrado multicapa con "pelado" de capas en cada nodo (estilo Tor).Bitcoin P2P (Web3): Simulación de Gossip Protocol, Mempool y minería básica mediante Proof-of-Work (PoW).QUIC & UDP: Comparativa entre transporte rápido sin conexión y el nuevo estándar multiplexado.🧅 Tutorial: Cómo probar el Onion RoutingLa joya de este simulador es la capacidad de enviar mensajes que ningún nodo intermedio (excepto el origen y el destino) puede leer.Construcción de la "Cebolla": El emisor cifra el mensaje $N$ veces con las llaves de los nodos intermedios.Tránsito: Cada relay recibe el paquete, descifra la capa exterior para ver a quién debe enviarlo, pero no puede ver el contenido final.Salida: El último nodo entrega el payload original al destino.Python# Ejemplo de flujo interno

🛠️ Componentes del Simulador1. NetworkSimulatorEl orquestador global. Utiliza un algoritmo BFS (Breadth-First Search) para calcular rutas óptimas entre nodos y gestiona la latencia acumulada.2. ProtocolFactoryPermite instanciar cualquier protocolo bajo demanda. Ideal para comparar cómo se comporta un mismo mensaje bajo TCP vs. UDP.3. Sistema de NodosCada nodo tiene atributos de:Reliability: Probabilidad de que el nodo procese el paquete correctamente.Bandwidth: Capacidad de transferencia que limita el flujo.Malicious Flag: Nodos marcados que pueden comprometer la seguridad.📊 Métricas de RendimientoAl terminar una sesión, el simulador arroja datos críticos:Average Latency: El tiempo medio de ida y vuelta (RTT).Delivery Success Rate: Porcentaje de paquetes que sobrevivieron a la fiabilidad de los nodos.Security Breaches: Conteo de paquetes interceptados por nodos maliciosos.
